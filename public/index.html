            Live

            Plug 3FS Rural Home into Claude Code or any AI agent that speaks MCP. Free for 25 checks a day; add your Pro key for unlimited.

            Claude Code
            claude mcp add --transport http usda-3fs https://usda.3fs.app/mcp

# with your Pro key (unlimited)
claude mcp add --transport http usda-3fs https://usda.3fs.app/mcp \
  --header "Authorization: Bearer rh_your_key"

            Then just ask: "Can a family of 5 making $72k get a USDA loan near 31201?"

            Any terminal
            # Mac / Linux
curl -s https://usda.3fs.app/mcp -H "content-type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"check_zip","arguments":{"zip":"30513","people":4,"income":68000}}}'

# Windows PowerShell
$body = '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"check_zip","arguments":{"zip":"30513","people":4,"income":68000}}}'
(Invoke-RestMethod https://usda.3fs.app/mcp -Method Post -ContentType 'application/json' -Body $body).result.content[0].text
